# MAP RULES — GEMINI
Use current RP state and short ATLAS GEMINI MIN. Output one full HTML document with MAP_DATA v2.0.0; never advance time, decide quest, invent NPCs or expose unknown secrets. Gemini sends PC place, narrative metadata, RP-related nearby places, actors and events; GitHub looks up the complete surroundings and builds all default layout, furnishings and SVG.
Required fields: schemaVersion,meta:{date,time,areaName,quote},atlasAnchor,pcPlace,pcSpot,places:[],actors:[exactly one isPC:true],events:[]. Optional: mapMode:'indoor|outdoor',layoutType,forceSandbox,region. Actor/event places resolve through id/name, NPC spot must be explicit.
Fixed: no props/architecture/size/construction. Generated: props only for real RP changes, not default inventory. propsMode:'merge|replace', props:[{name,item?,id?,count?,op?:'ensure|add',state?,zone?,visual?}]. Whole objects only; no parentId/childId/supportId. Missing SVG: Gemini may supply safe visual shapes, GitHub renders or reports technical fallback.
EVENT hidden:false = ! binoculars; hidden:true = ? magnifier. No quest quotas, reward, item lists, zoom, random seed or atlas room arrays in MAP_DATA. Vietnamese visible descriptions; escape '<' in JSON strings as \\u003c. Fill all placeholders.
